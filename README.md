# StefaX

A fast, private desktop browser built on Chromium.

## Download

Get the latest version from [Releases](https://github.com/renandgoat-maker/stefax/releases/latest):

| Device | File |
| --- | --- |
| Windows 10 and 11 PC or laptop (Intel or AMD) |  |
| Windows 11 laptop with an ARM chip (Snapdragon, for example Surface Pro X / Copilot+ PCs) |  |
| Android 10 or newer phone |  |

Not sure which Windows file? Open Settings > System > About and look at "System type":
"x64-based processor" takes the first file, "ARM-based processor" the second.

The Windows app checks for updates by itself and installs them when you restart it.
Windows may show "Windows protected your PC" because the installer is not code
signed: click **More info**, then **Run anyway**.

On Android, open the APK on your phone and allow installing apps from that source
when asked. To update, install the newer APK over the old one; your tabs and
bookmarks stay.

## Features

- Tabs, tab groups, split view, pinned tabs and a memory saver for unused tabs
- Tracker blocking, HTTPS-only mode and private windows
- Chrome Web Store extensions
- Passwords and addresses saved and filled in for you
- Reader mode, dark mode for websites, picture-in-picture and screenshots
- Profiles, bookmarks, history and import from other browsers
